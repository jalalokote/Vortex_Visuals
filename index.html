🎛️ ¿Cómo funciona esta herramienta?

Te permite usar toda esta interfaz web (12 perillas rotativas con nombres de canal editables, MIDI desde Purr Data, triggers, audio FFT y BPM) como una consola de control en vivo para TouchDesigner sin programar redes complejas.

📋 Requisitos paso a paso

  1. Paso 1: Tener TouchDesigner instalado y abierto en tu computadora local.
  2. Paso 2: En tu proyecto .toe, agrega un nodo WebSocket DAT conectado a ws://localhost:8080 (o usa un Web Server DAT en tu puerto preferido) para recibir los paquetes JSON td_control, td_trigger, td_media y td_audio.
  3. Paso 3: Opcionalmente, personaliza los nombres de las perillas con el botón ✏️ para que coincidan con los parámetros de tu red en TouchDesigner.
Por defecto usa el Hub local ws://localhost:8080 (que también recibe UDP de Purr Data) o ingresa el puerto de tu Web Server DAT (ej. ws://localhost:9980).
